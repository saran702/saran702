🚀 Featured Projects
01. Behavioural Analysis for Detecting Fileless and Stealth Malware
<sub>2026 · Malware Analysis · Machine Learning</sub>
A behaviour-based malware detection system designed to identify fileless, stealth, and previously unknown malware by analysing runtime system and memory activity instead of depending only on file signatures.
Key work
Modelled interactions between processes, memory, and system resources using a graph-based approach.
Applied an Isolation Forest model for anomaly detection.
Calculated a Behavioural Risk Index (BRI) to represent threat severity.
Generated forensic-style reports to support security investigations.
02. URL-Based Attack Classifier
<sub>2026 · Web Security · Machine Learning · Streamlit</sub>
A system that analyses network logs to detect URL-based attacks and helps analysts review suspicious activity.
Key work
Detects attack patterns such as SQL Injection, XSS, Directory Traversal, and Command Injection.
Combines rule-based detection with machine learning.
Provides a Streamlit dashboard for reviewing detected attacks and generating reports.
03. CryptGuard
<sub>2025 · Audio Security · Encryption</sub>
A voice-based audio encryption system that uses speaker verification to help restrict access to protected audio files.
Key work
Used Dynamic Time Warping (DTW) for speaker verification.
Used Fernet encryption for secure audio storage.
Designed access so that authorised users can decrypt files within a specified time window using the correct key.
Future enhancements include web-based implementation and real-time alerting.
