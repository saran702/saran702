1. Behavioural Analysis for Detecting Fileless and Stealth Malware
<sub>2026 · Malware Analysis · Machine Learning</sub>
Developed a behaviour-based malware detection system to identify fileless, stealth, and previously unknown malware by monitoring runtime system and memory activity rather than relying only on traditional file signatures.
Key Features
Modelled interactions between processes, memory, and system resources using a graph-based approach.
Applied an Isolation Forest machine learning model for anomaly detection.
Calculated a Behavioural Risk Index (BRI) to quantify threat severity.
Generated forensic-grade reports for security investigations.
Concepts: `Behavioural Analysis` `Graph-Based Modelling` `Isolation Forest` `Anomaly Detection`

<sub>2025 · Audio Security · Encryption</sub>
